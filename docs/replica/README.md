# LobeHub 复刻指南（小白版）

> 适用对象：编程基础较弱，想通过 **vibe coding**（让 AI 写代码）复刻 LobeHub，
> 并只保留自己需要的功能。
> 所有分析基于已下载到 `refs/lobe-chat` 的 LobeHub 源码（canary 分支，v2.2.17）。

## 先说结论（30 秒版）

1. **不要逐行复刻**：LobeHub 约 150 万行代码、1.5 万个文件，是大团队 3 年的积累。
   个人 + AI 的现实目标是做一个"**功能复刻的简化版**"：几万行代码，覆盖 80% 的体验。
2. **怎么复刻才合法**：参考它的设计、自己写代码 ✅；直接改它的源码后商用 ❌（要买授权）。
   它的 UI 组件库 lobe-ui / lobe-icons 是 MIT 协议，**可以直接安装使用**——外观一步到位。
   详见 [05](./05-许可证与合规.md)。
3. **怎么做**：按 [04 路线图](./04-vibecoding实操路线图.md) 的 5 个阶段走，
   每个阶段一个可验收的小目标；想砍哪些功能，对照 [03 蓝图](./03-复刻蓝图-核心与可裁剪.md)。
