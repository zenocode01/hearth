# 05 · 许可证与合规（决定"怎么复刻才合法"）

> 一句话结论：**学它的设计、自己写代码、直接装它的 MIT 组件库 = 完全没问题；
> 把它的源码改一改再对外发行 = 要买授权。**

## 1. 涉及的三份许可证

| 代码 | 许可证 | 一句话含义 |
|---|---|---|
| **LobeHub 主仓库**（lobe-chat 源码） | **LobeHub Community License** = Apache-2.0 **+ 2 条附加条款** | 见下面 §2 逐条翻译 |
| **@lobehub/ui**（lobe-ui 组件库，2200+ star） | **MIT** | 最宽松的开源协议：随便用、改、分发、商用，保留原许可声明即可 |
| **@lobehub/icons**（AI 品牌图标库） | **MIT** | 同上 |

## 2. LobeHub Community License 附加条款（原文逐条翻译）

> 基础是 Apache-2.0（允许任何人使用、修改、分发，含商用），附加两条：

**第 1 条（关于你）**
- **1a. 不改源码 → 随便用，商用也行**：
  把 LobeChat 原样部署成前后端服务（比如公司自用、甚至对外提供
  和你未修改的原版相同的 LobeChat 服务）✅ 合法。
  → 对应你的选项 C：Docker 自托管原版。
- **1b. 改源码做"衍生作品"再分发 → 必须向他们买商业授权**
  （联系 hello@lobehub.com）。
  → 也就是说：**fork 它的代码 → 修改 → 对外发行/商用**，需要付费授权。
  （非商业的个人学习/自用修改，落在 Apache-2.0 基础范围内，
  但**保留原许可与版权声明**是义务。）

**第 2 条（关于贡献者，与你基本无关）**
- 你向它贡献代码 = 同意 LobeHub 可调整开源协议松紧 + 可把你的代码
  商用（包括用在它的云版本里）。→ 不打算给它提 PR 的话，无影响。

## 3. 三条路线对比（你该选哪条）

| 路线 | 做法 | 合法性 | 适合谁 | 代价 |
|---|---|---|---|---|
| **A. 参考设计，自己写**（✅ **推荐**） | 读它的文档/设计/架构（本指南 + refs/），让 AI **写你自己的代码**；外观直接用 MIT 的 @lobehub/ui / @lobehub/icons | 完全干净：代码 100% 是你的，想怎么用怎么用（含商用） | **想"复刻并自定义裁剪"的你** | 需要自己走 [04 路线图](./04-vibecoding实操路线图.md) |
| B. Fork 源码魔改 | 直接拿 150 万行源码改 | 个人学习/自用：OK（Apache-2.0 基础部分，保留许可声明）；**对外发行/商用：要买授权** | 有企业诉求或深功底的人 | 150 万行对小白是灾难现场；商用要谈判买授权 |
| C. 原样使用（Docker 自托管） | 部署未修改的原版 | 完全合法（条款 1a） | 只想"用"不想"做"的人 | **不能裁剪**——它是什么样就是什么样 |

## 4. 路线 A 的"合法边界"实操（vibe coding 时怎么拿捏）

1. **学思路 ≠ 抄代码**。对 AI 说"**参考** refs/lobe-chat/xxx 的**实现思路/数据结构/交互**，
   用我们自己的方式实现"——得到的代码是你项目的原创代码 ✅。
2. **避免整段复制粘贴** LobeHub 主仓库的文件到你自己项目（尤其改得面目全非后
   对外发布——那会构成"衍生作品"，落在条款 1b）。
   个别极小的通用代码片段（几十行的工具函数）业界通常认为无版权意义，
   但**能重写就重写**，别赌边界。
3. **MIT 组件随便用**：`@lobehub/ui`、`@lobehub/icons` 通过 npm 安装即用，
   其源码自带 MIT 声明（保留在包内即可），无署名/商标义务，商用无忧。
   注意：**"LobeHub"的名字和 LOGO 是商标**——你的产品叫自己的名字，
   别说"这是 LobeHub"（可以说"参考了 LobeHub 的设计"）。
4. **图标注意**：lobe-icons 里是各家 **AI 品牌**（OpenAI/Anthropic/…）的 LOGO。
   图标库是 MIT，但那些 LOGO 的商标权在各自品牌手里——
   自用/内部展示没问题，如果你的产品面向大众，给品牌图标加"仅供参考"的
   处理或只用自绘图标，最稳。
5. 你的项目 README 里写一句：
   "本项目为独立实现，设计参考了 LobeHub（LobeHub Community License），
   使用 MIT 协议的 @lobehub/ui 与 @lobehub/icons 组件库" —— 坦坦荡荡，
   也是给未来自己/投资人看的合规档案。

## 5. 一张图总结

```
LobeHub 全家桶
├── 主仓库（150万行，Community License）
│     用原版（不改）     → ✅ 随便（含商用）
│     改源码·自用/学习   → ✅（保留许可声明）
│     改源码·对外发行    → ⚠️ 需商业授权
├── @lobehub/ui（MIT）   → ✅ 随便用改，装即用
└── @lobehub/icons（MIT）→ ✅ 同上（注意里面品牌 LOGO 的商标归属）
```

**你的路线**：主仓库当"参考书"（refs/ 已就位，只读）+ 自己写简化版 + 装 MIT 组件。
